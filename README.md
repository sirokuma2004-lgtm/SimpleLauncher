# SimpleLauncher

文字だけで操作するミニマルな Android ランチャーのデモです（Kotlin + Jetpack Compose）。

## デザイン
黒一色の背景に白いドット、アクセントは赤い点ひとつだけ。等幅フォントの小さなラベルを添えています。

## できること
- ホーム画面
  - ドットで描いた大きな時計（コロンが点滅）と日付・週番号。時計をタップするとアラームが開きます
  - 時間帯に合わせたあいさつ
  - ウィジェット：電池の丸メーター、日付カード、ストレージの丸メーター、RAM・電池・温度をまとめたカード（RAM 使用率の推移をドットのグラフで表示）
  - 右下の網点模様と、画面全体に敷いた薄いドットの格子
  - お気に入りアプリ（最大7件）を等幅の大文字で一覧表示。押している間だけ赤い点が付きます。長押しで外れます
- 上にスワイプするとアプリ一覧（角丸パネル、4列、白黒アイコン）が開きます
  - 検索欄にすぐ入力できます。候補が1件に絞れたら自動で起動します
  - 長押しメニューから「ホームに追加 / 外す」「アプリ情報」を選べます
- 戻るボタン・ホームボタン・下スワイプ・パネルの外側をタップすると一覧を閉じます

## ビルド
Android Studio でこのフォルダを開き、実機かエミュレータで Run してください。
インストール後に「設定 → アプリ → デフォルトのアプリ → ホームアプリ」で SimpleLauncher を選ぶとランチャーとして動きます。

- minSdk 26 / targetSdk 35
- AGP 8.7.3 / Kotlin 2.0.21 / Gradle 8.10.2
