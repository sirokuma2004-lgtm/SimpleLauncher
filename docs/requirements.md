# SimpleLauncher 要件定義

## 目的
- 自分用。毎日使うホーム画面として使う
- 見た目の凝り具合より、毎日の使い勝手と安定性を優先する
- 他人向けの設定項目、多言語対応、ストア公開向けの対応はしない

## 対象環境
- 端末：Xiaomi（HyperOS 3 / Android 16）
- Android 16 を基準に作り、この端末で確認する。古いバージョンへの対応は最小限

## デザインの方針
- 白黒にアクセントの赤ひとつ。ドットと等幅文字
- ダーク：黒地に白いドット／ライト：白地に黒いドット。赤のアクセントは共通

## 機能

### 必須
| 機能 | 内容 |
|---|---|
| 時計 | 7種類（Dot / Stack / Thin / Segment / Ring / Binary / Words）から選ぶ。秒と点滅は出さず、1分ごとに更新。Dot のコロンは縦2点 |
| 複数ページ | 左右にスワイプして切り替える。ページごとに「テンプレート」か「自由配置」かを選ぶ |
| ドック | 画面下に固定。5つ。表示はアイコンか文字かを選ぶ。文字はアプリごとに自由に設定できる |
| お気に入り | 表示する文字をアプリごとに自由に設定できる |
| アイコンパック | 対応する。表示は白黒で統一 |
| 壁紙 | ドット模様（初期設定）／端末の壁紙／単色から選ぶ。壁紙を暗くする度合いを調整できる。白黒にするかを選べる |
| ダーク／ライト | 切り替えられる |
| 文字サイズ | 調整できる |
| 再生中の音楽 | 曲名と再生操作を表示する（通知へのアクセスの許可が必要） |

### あれば嬉しい
- Android 標準のウィジェット
- アプリを隠す（一覧に出さない）
- 長押しで編集（実装済み）
- 天気ウィジェット

### 入れない
- 上記以外（フォルダ、通知バッジ、拡張検索、ジェスチャーの割り当てなど）

## 進め方
| 段階 | 内容 | 完了の基準 |
|---|---|---|
| 第1段階 | ドック、複数ページ、お気に入りとドックの文字変更、秒なしの時計 | 実機でホームアプリに設定し、毎日使い始められる |
| 第2段階 | 壁紙、ライトモード、文字サイズ、アイコンパック | 見た目の設定が一通りそろう |
| 第3段階 | 再生中の音楽、「あれば嬉しい」の項目 | ― |

## 実機で早めに確かめること
- HyperOS で他社製ランチャーを使ったときのジェスチャー操作（ホームに戻る、最近使ったアプリ）
- 電池の節約機能で音楽の表示が止まらないか（自動起動の許可、電池の制限の解除が必要か）
